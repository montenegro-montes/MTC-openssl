# Representative combined-network TLS experiment

Results cover controlled Docker profiles and are not estimates of every real network. RTT, bandwidth and loss effects interact; isolated-experiment effects must never be summed. MTC remains `MTC-experimental` targeting `draft-ietf-plants-merkle-tree-certs-05`.

Primary results: `main-table.csv`. All scenarios: `scenario-summary.csv`. Paired common-success-round effects and 10,000-resample campaign bootstrap intervals: `paired-table.csv`. Failures remain in `failures.csv`. TCP retransmissions are campaign-level only and are not attributed to individual TLS connections. TLS BIO bytes are not wire bytes.
