# Cryptographic scaling studies

This category contains experiments whose independent variables are
cryptographic profiles or authentication-structure sizes. It is separate from
the validation, performance, network-condition and packet-capture campaigns.

| Directory | Study | Status |
|---|---|---|
| `cert_chain_scaling/` | ECDSA, ML-DSA and SLH-DSA certificate sizes; X.509 chain depth; MTC proof scaling and crossover | Prepared for manual execution |

New studies involving key type, security level, key or signature length,
certificate-chain depth, or Merkle proof length should be placed in this
category. Each study retains its own immutable fixture and result roots.
