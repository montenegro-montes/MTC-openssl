# Paper datasets

Public data and reproduction instructions for papers based on this repository.
Each paper has its own directory:

- [`commag/`](commag/README.md): IEEE Communications Magazine, Figures 4 and 5 and Table I.

Keep new runs in new directories and retain their configuration, source
versions, image IDs, measurement counts, and analysis scripts. Review raw
files for private keys, machine-specific paths, and unrelated captures before
adding them here.
